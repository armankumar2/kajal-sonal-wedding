# काजल ♥ सोनल | Mobile Wedding Invitation

Mobile-first Hindi wedding invitation built with React, Vite, Framer Motion, GSAP and Lucide React.

## Run locally
`npm install` then `npm run dev`.

## Vercel
Build command: `npm run build`
Output directory: `dist`

Optional licensed shehnai/flute audio can be placed at `public/assets/shehnai-flute.mp3`. RSVP is decorative only and does not collect data.
